# 小兔鲜电商项目 - 前端

## 📌 项目简介
基于 Vue3 + Vite 开发的电商前端项目，是「小兔鲜电商平台」的用户交互部分，实现了商品浏览、购物车、用户登录、订单管理等核心电商功能，与后端 API 项目 `mall-api` 配合使用。

## 🛠️ 技术栈
- 核心框架：Vue 3（组合式API）
- 构建工具：Vite
- 状态管理：Pinia（替代Vuex）
- 路由管理：Vue Router 4
- HTTP 请求：Axios（封装了请求拦截器）
- 样式：SCSS + 组件库

## 🚀 项目启动
```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（默认端口5173）
npm run dev

# 3. 打包构建生产环境
npm run build
